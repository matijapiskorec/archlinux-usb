# LibreOffice

LibreOffice tips and tricks.

## How to export PDF table in Calc

If you only want to export a PDF table (for example, to include it in LaTeX document) you can do it `Export as PDF` dialogue by selecting `Structure` and then `Whole sheet export`.

## How to minimize size of presentation

You can either export to PDF and reduce the JPEG compression from 95% to a lower value.

Or you can use `Tools -> Presentation Minimizer` to reduce the size of the presentation. This will probably save it to ODP format which is more compact, and then you can additionally export it to PDF as well.
